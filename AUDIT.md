### Решение по проблеме 9

`selectedParentId` вычисляется и возвращается из хука, но ни один компонент его
не читает. Формально это мёртвый код, однако поле является частью публичного
контракта `UseShapesResult` и нужно для операций вида «вынести в родителя»,
которые ещё не реализованы. Удаление сейчас не даст выгоды и сделает
последующую доработку дороже, поэтому поле оставлено как есть.

## Что осталось за рамками аудита

- Автосохранение реализовано в `localStorage`; при очистке данных браузера работа
  теряется. Серверного хранения нет — оно не запрашивалось.
- Текст не переносится по ширине автоматически: высота текстового узла задаётся
  вручную и не подстраивается под содержимое. Это ограничение, а не дефект.
- Проверка по правилам AGENTS.md для этого проекта — `npm run build`,
  `npm run lint`, открытие в браузере с чтением консоли.
  `node --check` к TypeScript неприменим, `python -m py_compile` — в проекте нет
  Python.
